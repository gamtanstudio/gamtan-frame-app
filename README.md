# 감탄 액자 키오스크 앱 (GamtanKiosk)

전원을 켜면 자동으로 실행되어 `감탄 액자` 화면만 전체화면으로 띄우는 전용 앱입니다.
Fully Kiosk 대신 쓰는, 감탄사진관 전용 키오스크예요.

## 이 앱이 하는 일
- **자동부팅**: 홈(런처) 앱으로 등록하면 전원만 켜도 액자가 뜸 (부팅 자동실행 백업 기능도 포함)
- **전체화면**: 상단바·네비게이션바 숨김
- **화면 항상 켜기**: 절전으로 꺼지지 않음
- **잠금**: 뒤로가기 차단 + 홈 앱이라 빠져나갈 곳이 없음 (부모님이 못 나감)
- **토큰 입력 화면**: 첫 실행 때 액자 토큰만 붙여넣으면 됨
- **와이파이 미연결 안내**: 연결이 안 되면 액자 번호·연락처와 "와이파이 설정 열기" 버튼 표시

## 핵심 (왜 안드6에서도 그냥 되나)
액자 화면(`app/src/main/assets/frame.html`)의 디자인·동작은 기존 `frame-legacy.html` 과 동일합니다.
단, Supabase 통신을 **앱이 대신** 처리합니다.
- 사진 목록(POST `rpc/frame_manifest`)은 앱이 직접 호출
- 사진/배경 이미지(GET)는 앱이 요청을 가로채 직접 받아옴
- 두 경우 모두 **ISRG Root X1/X2 인증서를 앱에 내장**해서 검증

그래서 안드로이드6 같은 옛 기기에서도 웹뷰 업데이트나 인증서 설치 없이 사진이 뜹니다.
관리 화면(사진 업로드)·Supabase 창고는 지금 그대로 씁니다. 바뀐 것 없습니다.

## APK 받는 법 (추천: GitHub Actions — 컴퓨터에 아무것도 설치 안 함)

1. GitHub(gamtanstudio 계정)에서 새 저장소를 만듭니다. 예: `gamtan-frame-app`
2. 이 폴더의 모든 파일을 그 저장소에 올립니다(push).
   - GitHub Desktop을 쓰면: 이 폴더를 저장소로 추가 → Commit → Push
   - 명령어로 하면:
     ```
     git init
     git add .
     git commit -m "감탄 액자 키오스크 앱"
     git branch -M main
     git remote add origin https://github.com/gamtanstudio/gamtan-frame-app.git
     git push -u origin main
     ```
3. 저장소의 **Actions** 탭으로 가면 "Build APK" 가 자동으로 돌아갑니다(약 2~4분).
4. 완료된 실행을 열고 아래 **Artifacts** 에서 `gamtan-frame-debug-apk` 를 내려받습니다.
5. 압축을 풀면 `app-debug.apk` 가 나옵니다. 이게 설치할 파일이에요.

> 코드를 고친 뒤 다시 push 하면 APK가 자동으로 새로 빌드됩니다.

## APK 받는 법 (다른 방법: 안드로이드 스튜디오)
- Android Studio로 이 폴더를 열고 → Build → Build APK(s) → `app/build/outputs/apk/debug/app-debug.apk`

## 액자에 설치하기
1. 액자에서 "출처를 알 수 없는 앱 설치"를 허용 (설정 → 보안).
2. `app-debug.apk` 를 USB나 파일로 옮겨 설치.
3. 처음 실행하면 **토큰 입력 화면**이 나옵니다. 액자 토큰을 붙여넣고 저장.
   - 예) 테스트 액자 GT-0003 토큰: `e7c1d842-0762-46a5-8620-048f90b5e80c`
   - 액자 번호/연락처도 넣어두면 와이파이 미연결 안내 화면에 표시됩니다.
4. **홈 앱으로 지정**: 홈 버튼을 누르면 "홈 앱 선택"이 뜹니다. `감탄 액자` 를 고르고 "항상"을 선택.
   → 이제 전원만 켜면 액자가 자동으로 뜹니다.

## 부모님 댁 첫 와이파이 연결
부모님 댁 와이파이 비밀번호는 앱이 미리 알 수 없어, 처음 한 번은 현장에서 잡아줘야 합니다.
- **제일 매끄러운 길**: 주문 때 자녀에게 부모님 댁 와이파이 이름·비번을 받아, 출고 전 스튜디오에서 미리 연결해 두기 → 부모님 댁에서 전원만 꽂으면 자동 연결(현장 세팅 0회).
- **현장에서 잡을 때**: 전원을 켜고 약 15초 안에 인터넷이 안 잡히면 **와이파이 설정이 자동으로 뜹니다.** 집 와이파이를 골라 비번을 넣고 홈으로 나오면 곧 사진이 뜹니다. 화면의 "와이파이 설정 열기" 버튼으로도 언제든 열 수 있어요.
- 자동으로 뜨는 건 **부팅당 한 번만** 입니다(공유기가 잠깐 끊길 때마다 튀어나오지 않게).

## 나중에 설정 다시 열기 (숨은 문)
- 화면 **왼쪽 위 구석을 5번 연속 탭** 하면 "액자 정보" 창이 뜹니다.
- 거기서 `지금 새로 받기`, `와이파이 설정`, `액자 설정`(토큰 변경) 을 쓸 수 있어요.

## 세로/가로 바꾸기
- 기본은 세로입니다. 가로로 쓰려면 `app/src/main/AndroidManifest.xml` 에서
  `android:screenOrientation="portrait"` 를 `"landscape"` 로 바꾸고 다시 빌드하세요. (두 군데)

- 패키지명: `com.gamtan.frame` / 앱 이름: 감탄 액자
